# mNotch for macOS

Installers and automatic updates for **mNotch**, part of mSuite by Merit Concept.

**Download:** open the [latest release](https://github.com/meritconcepttz-hub/mnotch-releases/releases/latest), download `mNotch-<version>.dmg`, open it and drag mNotch to Applications.

Installed copies update themselves from here. This repository holds installers only.
